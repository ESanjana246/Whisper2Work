# 🎙️ Whisper2Work

## Turn Your Words into Work

Whisper2Work is an AI-powered productivity assistant that transforms natural-language instructions into structured tasks.

Instead of manually entering task details, users can simply describe what they need to do, and AI extracts the task, deadline, priority, and category automatically.

## 💡 Problem Statement

People often have tasks and ideas in their minds but spend additional time manually organizing them into task managers.

Traditional task management requires users to enter multiple details such as:

- Task title
- Deadline
- Priority
- Category

Whisper2Work simplifies this process using AI.

---

## 💡 Our Solution

Users can describe their task naturally.

### Example:

> Finish my machine learning project by Friday with high priority.

Whisper2Work intelligently extracts:

- 📝 Task: Finish machine learning project
- 📅 Deadline: Friday
- 🔥 Priority: High
- 🗂️ Category: Project

The task is then added to the productivity dashboard.
